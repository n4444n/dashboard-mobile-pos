# Tally — แอปมือถือรายงานยอดขาย (Mobile Apps 1.0.0)

แอปมือถือสำหรับเจ้าของร้าน/ผู้จัดการ ดูยอดขายจาก **Clothing POS** แบบเรียลไทม์
โครงหน้าจอตามไฟล์แบบ `Tally_POS_Reports.html` · ใช้สแตกเดียวกับ POS 1.0.33

| | |
|---|---|
| เฟรมเวิร์ค | Expo SDK 54 · React Native 0.81.4 · React 19.1 · TypeScript 5.9 (เหมือน POS) |
| กราฟ/ไอคอน | react-native-svg 15.12 (ไอคอนชุดเดียวกับไฟล์แบบ) |
| ฟอนต์ | Prompt (หัวข้อ/ตัวเลข) + IBM Plex Sans Thai (เนื้อหา) |
| เก็บค่าในเครื่อง | @react-native-async-storage/async-storage |
| ข้อมูล | API จริงของเซิร์ฟเวอร์ POS (อ่านอย่างเดียว ไม่แก้ข้อมูลใน POS) |

## เริ่มใช้งาน (เครื่อง PC)

1. ดับเบิลคลิก `run-mobile.bat` — ครั้งแรกจะ `npm install` + `npx expo install --fix` ให้เอง
2. ติดตั้งแอป **Expo Go** (SDK 54) บนมือถือ แล้วสแกน QR ที่ขึ้นในหน้าต่าง
3. มือถือและ PC ต้องอยู่ Wi-Fi เดียวกัน

`run-mobile.bat web` = เปิดในเบราว์เซอร์ · `run-mobile.bat tunnel` = ใช้เมื่อมือถือคนละเครือข่าย

## เข้าสู่ระบบ (เหมือนโปรแกรม POS .exe)

1. **License** `POS-XXXX-XXXX` → `POST <license>/api/activate` → ได้ที่อยู่ร้าน + ชื่อย่อร้าน (แอปนับเป็น 1 เครื่อง)
2. **PIN พนักงาน** → `POST /api/auth/login` → token · ต้องเป็นพนักงานที่มีสิทธิ์ "รายงาน" (ผู้จัดการ/ผู้ดูแลระบบ)
3. ทุกครั้งที่เปิดแอปจะ `POST /api/check` — หมดอายุ/ถูกระงับ → กลับหน้า License

### ทดสอบกับเซิร์ฟเวอร์ในเครื่อง
หน้า License › **ตั้งค่าเซิร์ฟเวอร์**
- ผ่าน License: เซิร์ฟเวอร์ License = `http://<IP เครื่อง PC>:3100` (เปิดด้วย `run-test.bat` ของ POS)
- ต่อตรง (ข้าม License): `http://<IP เครื่อง PC>:3000` → เข้าหน้า PIN ทันที (PIN ผู้จัดการทดสอบ 999999)

## หน้าจอ

| แท็บ | เนื้อหา |
|---|---|
| หน้าหลัก | ยอดขายสุทธิ (ซ่อนได้) · การ์ดสาขาปัดซ้าย-ขวา · ปุ่มลัด · KPI · กราฟ · บิลล่าสุด |
| รายงาน | 15 รายงาน: สรุปยอดขาย, รายชั่วโมง, ช่องทางชำระ, รายการบิล, สินค้าขายดี, หมวดหมู่, ไซซ์/สี, สินค้าคงคลัง, ส่งของจากโรงงาน, ค่าใช้จ่าย, ปิดกะ, เปรียบเทียบสาขา, พนักงาน, กำไร-ต้นทุน, คืน/ยกเลิก |
| ปุ่มกลาง | ซิงค์ข้อมูลล่าสุด (หรือดึงหน้าจอลง) |
| สต็อก | มูลค่าสต็อก · ใกล้หมด · หมด · สต็อกตามสี/ไซซ์ ค้นหาได้ |
| การตั้งค่า | ภาษา (ไทย/English) · License · ตั้งค่า API · ออกจากระบบ |
| กระดิ่ง | กิจกรรม 2 วันล่าสุด (บิลยกเลิก/แก้ไข, บิลยอดสูง, เปิด-ปิดกะ, ค่าใช้จ่าย, ส่งของ, สต็อกหมด) |

แตะบิล/ค่าใช้จ่าย/ใบส่งของ → แผ่นรายละเอียดเลื่อนขึ้นจากด้านล่าง

## API ที่ใช้ (ทั้งหมดเป็น GET ยกเว้นเข้าระบบ/สลับสาขา)

| endpoint | ใช้ที่ |
|---|---|
| `/api/dashboard?from=&to=&branch=all\|<id>` | หน้าหลัก + รายงานส่วนใหญ่ |
| `/api/history` · `/api/orders/{id}` | รายการบิล · ใบเสร็จ · คืน/ยกเลิก · กิจกรรม |
| `/api/shifts` · `/api/expenses` · `/api/shipments` | ปิดกะ · ค่าใช้จ่าย · ส่งของ |
| `/api/stock/skus` | สต็อก |
| `/api/branches` · `POST /api/branches/switch` | สาขา (บิล/กะ/สต็อกเป็นของสาขาใน session → ดูทุกสาขา = เรียกทีละสาขาแล้วรวม) |

ไม่ต้องแก้เซิร์ฟเวอร์ POS — ใช้ API ที่มีอยู่แล้วในรุ่น 1.0.33

## โครงสร้างไฟล์

```
App.tsx                 ขั้นตอนเข้าระบบ + โครงแอป (แท็บ, ปุ่มย้อนกลับ Android, ซิงค์)
src/api.ts              เรียก API ร้าน + License (X-POS-Shop, Bearer token, สลับสาขาแบบคิว)
src/state.tsx           สถานะกลาง + useLoad()
src/theme.ts            สี (สว่าง/มืด ตามเครื่อง) ฟอนต์ เงา — ตามไฟล์แบบ
src/i18n.tsx            ไทย/English  t('ไทย', 'English')
src/activity.ts         รวมกิจกรรมล่าสุด
src/components/         ui (แผง KPI ชิป ตาราง sheet) · Charts · Icon · BillRow · Sheets · Chrome (หัว/เมนูล่าง)
src/screens/            Login · Home · Reports (+ reports/Bodies) · Stock · Activity · Settings
```
